Sidewalk Stewards is a visual analytics system that bridges the gap between automated extraction and a deployment-ready pedestrian network. Sidewalk Stewards detects candidate topology errors, supports interactive user-guided correction through coordinated spatial views, and provides real-time quality feedback as edits are applied. We evaluate the system through case studies showing how it can support the creation of reliable pedestrian networks across different cities.
